# Mục tiêu dự án — Social / Facebook Page (đa Page)

## Vấn đề
Doanh nghiệp (ví dụ khách sạn / OTA / lễ tân) cần **page vận hành** riêng để team đăng nhanh, theo dõi, không phụ thuộc chỉ một page “chính” thương hiệu.

## Mục tiêu
1. Sao chép nội dung (caption + ảnh) từ **Page nguồn** sang **Page đích** do người dùng chỉ định mỗi lần.
2. Không khóa một Page cố định trong system prompt — mỗi lệnh ghi rõ URL nguồn / đích.
3. Giữ chất lượng: đúng chữ, đủ ảnh album, đúng danh tính Page (không nhầm profile cá nhân).
4. Tối ưu tốc độ: 2 cửa sổ/tab browser (nguồn | đích), paste caption, upload file local.

## Ngoài phạm vi (trừ khi user yêu cầu)
- Đổi tên / cài đặt Page, chạy ads, spam comment/DM.
- Tự chọn Page khi thiếu URL.
